This page describes the privacy practices of **[rclone-proxmox](/rclone-proxmox/)**, a personal OAuth application I use to back up my own Google Drive accounts to my personal server using [rclone](https://rclone.org).

### Data access

* This application accesses only the Google account data belonging to the account holder who explicitly authorizes it.
* It reads files and folder metadata via the Google Drive API to create local backup copies. It does not modify, delete, or share the contents of any authorized Google Drive account.

### Data sharing

* This application is not distributed to, or used by, any third party — it is a private automation tool for personal backups only.
* No accessed data is shared, sold, or transmitted to any service other than the account holder's own storage.

### Revoking access

Access can be revoked at any time via [Google Account permissions](https://myaccount.google.com/permissions).
