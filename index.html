Technical debt · Software architecture · Infrastructure as code

Making the work of building software less accidentally hard.

Debt nobody can see, design intent that drifts away from the code, infrastructure left to rot in a repository - I work on the things that make building software harder than it needs to be. Through tools and measurement where those help, and by asking practitioners where they do not.

What I work on

Technical debt, managed

Shortcuts in code are a normal part of building software. The problem is that nobody can see what they will cost. I work on making debt measurable, trackable and repayable inside the tools teams already use.

Infrastructure as software

Deployment used to be configuration; now it is a codebase of its own. Terraform files and Kubernetes manifests rot like any other code, and we know far less about what they cost to run - in euros and in energy. I work on bringing software engineering to that layer, and next to the platforms teams build on it.
