Datasets

Data and catalogs from my studies that are useful on their own, not only for reproducing a result. Each one is cited in the paper it came from.

  • IaC Cost Patterns

    A living catalog of cost management patterns and antipatterns for infrastructure-as-code in cloud deployments, with the commits where each occurs. Open to community contributions.

    Catalog →Source →DOI →

    • From: Towards sustainable cloud deployments: A cost (anti)patterns catalog for terraform and CloudFormation · JSS 2026
    • From: A Catalog of Cost Patterns and Antipatterns for Infrastructure as Code · SEAA 2024

  • Cost awareness in cloud deployments

    Cost-related Stack Overflow questions, and GitHub commits and issues from cloud projects, coded for how developers handle cloud cost. About 33 MB, licensed separately for reuse.

    DOI →Source →

    • From: Mining for cost awareness in the infrastructure as code artifacts of cloud-based applications: An exploratory study · JSS 2024

  • Technical debt lifecycle dataset

    312 technical debt items traced from introduction through identification to repayment, across both issue trackers and source code, drawn from 3,000 sampled issues.

    DOI →Source →

    • From: The lifecycle of Technical Debt that manifests in both source code and issue trackers · IST 2023

  • Technical debt tooling discussions

    Cleaned Stack Exchange discussions on the adoption of technical debt tools, with an inventory of 51 tools and the rationales practitioners gave for choosing them.

    DOI →

    • From: Automating Technical Debt Management: Insights from Practitioner Discussions in Stack Exchange · TechDebt 2025
